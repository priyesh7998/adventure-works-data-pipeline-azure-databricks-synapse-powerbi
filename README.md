# Understanding Data

Data is a collection of recorded facts, observations, or measurements. On its own, a value may have little meaning; organized and interpreted in context, data can help answer questions, reveal patterns, and support better decisions.

## From data to insight

A useful data workflow typically includes:

1. **Collect** information from reliable sources.
2. **Validate** it for accuracy, completeness, and consistency.
3. **Transform** it into a structure that fits the intended use.
4. **Analyze** it to identify trends or answer specific questions.
5. **Communicate** the results clearly, with enough context to interpret them.

Good data work also considers privacy, security, ownership, and quality throughout the process. The goal is not simply to store more information, but to make trustworthy data useful to the people and systems that depend on it.
